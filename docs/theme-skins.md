# 主题皮肤

在「设置 → 主题皮肤」选择 Default Theme 或 Kuriyama Mirai。卡片下方可预览效果，主窗口也实时同步皮肤、背景参数和 CSS。点击保存才写入设置并同步其他窗口；取消、Esc、关闭设置窗口或离开设置页都会撤销临时预览，恢复已保存的皮肤。预览不会修改已保存的设置，重新打开时从上次保存的状态开始。

点击「新增皮肤」创建独立卡片，可以命名、选择基础配色、上传背景、编辑 CSS 和删除。每张自定义卡片分别保存参数。主题列表支持横向滚动、鼠标滚轮及左右箭头；新建后自动滚动到该卡片。在内置主题上上传背景或启用自定义 CSS 时，会创建独立副本，原来的两套内置主题仍然保留。

- **主题内置样式**：使用所选皮肤的配色。栗山未来主题包含粉色界面与适合浅色背景的终端文字颜色。
- **项目默认样式**：保留项目原有深色样式，可独立搭配主题背景或上传的背景。
- **自定义 CSS**：在所选皮肤的基础上追加 CSS，支持载入内置 CSS 后编辑。编辑时实时作用于预览和主窗口，保存后应用到其他窗口；设置页保留可操作的基础样式。

背景支持跟随主题、无背景和上传图片。可调节不透明度（0–100%）、模糊程度（0–20px）、铺满或完整显示，以及居中、顶部、底部、左侧、右侧对齐。默认不透明度为 30%，可单独重置背景参数。

不透明度和模糊参数使用公共 `AppSlider` 组件，带主题色进度填充和实时数值，支持拖动、点击及方向键调整。

上传支持不超过 10 MB 的 PNG、JPG、WebP。图片在本地转为 WebP，最长边最多 2560px，压缩后保存到现有设置中；不上传到服务器。存储不足时保留草稿并显示错误。

## 自定义样式示例

```css
:root {
  --color-violet: #c93478;
  --color-accent: var(--color-violet);
  --color-txt: #593a49;
  --color-panel: #fff8fbb3;
  --color-pane: #fffafbc4;
  --color-terminal: #fff9fbd9;
  --color-term-fg: #664654;
  --radius-pane: 12px;
}

.pane {
  border-radius: 16px;
}
```

内置样式位于 `src/assets/styles/skins/kuriyama-mirai.css`，原始背景素材位于 `src/assets/skins/kuriyama-mirai.png`。全部颜色变量可在 `src/assets/styles/main.css` 查看。

主题切换使用淡入淡出，左菜单、连接分组、SSH 机器面板和第二个 SSH 终端带展开/收起过渡。「外观 → 减少动画效果」及系统减少动态效果设置均会关闭动画。拖动分隔条调整宽度时不添加延迟。

设置窗口默认 1000 × 760，最小 740 × 560，支持拖动四边或四角缩放。原生窗口参数更改需要重新启动 Tauri 开发进程。数据库和 SSH 的 AI Agent 分屏左侧均有拖动分隔条；两种工作区分别记忆宽度，并在窗口缩小时限制宽度以保留编辑区。分隔条也支持方向键、Home 和 End。

## 验证

`pnpm test` 包含设置迁移、参数校验、多皮肤独立持久化、存储不足、快速切换主题与上传限制测试。启动 `pnpm dev` 后打开 `/tests/skin-preview.html`，可运行真实图片压缩、参数应用、下拉点击、终端配色、折叠动画、滑块和皮肤卡片检查。`/tests/agent-resize.html` 验证两类 AI 分屏的宽度边界、键盘操作、记忆宽度和容器缩小适配，也可手动拖动检查。

`/tests/skin-live-preview.html` 使用独立的设置页面验证主窗口实时预览、背景参数与 CSS 同步，以及取消、Esc、关闭、原生隐藏、快速切换和保存后的撤销边界。预览消息不写入持久化存储，并按会话和递增版本丢弃迟到更新。
