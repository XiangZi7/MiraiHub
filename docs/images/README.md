# README 图片维护 / README image maintenance

## 简体中文

两份 README 共用本目录的图片，文件名固定，替换时直接覆盖同名文件即可，无需改动 README。

| 文件 | 展示位置 | 建议 |
| --- | --- | --- |
| `overview.png` | 顶部产品展示图 | 16:9，宽度 ≥ 1600 px |
| `ssh-workspace.png` | SSH 终端与远端文件 | 16:10，宽度 ≥ 1440 px |
| `database-workspace.png` | 数据库工作台与 AI Agent | 同上 |
| `server-monitoring.png` | 服务器监控 | 同上 |
| `skin.png` | 主题皮肤与自定义背景 | 同上 |
| `ai-agent.png` | 备用，当前 README 未引用 | 竖版面板截图 |

截图前请隐藏或打码服务器地址、账号等敏感信息。如需新增图片位，两份 README 需同步修改。

## English

Both READMEs share the images in this directory. File names are fixed, so overwrite the file with the same name and no README change is needed.

| File | Slot | Suggested |
| --- | --- | --- |
| `overview.png` | Hero image | 16:9, width ≥ 1600 px |
| `ssh-workspace.png` | SSH terminal and remote files | 16:10, width ≥ 1440 px |
| `database-workspace.png` | Database workspace with AI Agent | same |
| `server-monitoring.png` | Server monitoring | same |
| `skin.png` | Theme skins and custom backgrounds | same |
| `ai-agent.png` | Spare, not referenced by the READMEs today | Portrait panel screenshot |

Hide or blur server addresses, accounts, and other sensitive data before capturing. When adding a new slot, update both READMEs.
