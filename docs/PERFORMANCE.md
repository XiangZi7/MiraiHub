## 行为与实现

- 远程编辑窗口恢复透明 WebView，应用用户选择的 Acrylic / Mica / 纯色材质，后续材质切换也包含编辑窗口。使用透明自绘标题栏，避免系统标题栏在 Acrylic 上出现不透明底块；保留拖动、双击最大化和窗口按钮，关闭仍经过未保存确认。正文只保留文件信息、操作、文本和状态，文本域不显示额外焦点框，详细保存说明折叠展示。
- 设置、连接和编辑子窗口在 Vue 路由、布局准备好后通过 `window_ready` 显示。两次动画帧给首屏绘制机会；隐藏 WebView 不回调帧时，100 ms 后继续，避免永久等待。
- 设置关闭后保留一个 WebView，卸载表单并清除未保存草稿；重开时重建表单、恢复通用页和已保存值。主窗口销毁时销毁缓存窗口。连续打开请求用后端互斥锁避免创建竞争。缓存占用一个 WebView 的常驻资源，换取重复打开的速度。
- 构建插件从源码提取实际使用的 Lucide 图标，保留离线能力；新增图标自动收集，缺失名称直接报构建错误。修正原有不存在的 `list-key` 图标。
- 44 点趋势线改成 SVG，去掉 ECharts 及其 Canvas 实例、resize observer 和深度 watcher。AI 与备份设置按需加载；SSH AI 面板首次使用才实例化，之后保留会话状态。
- `RemoteFileList` 负责可见行渲染、焦点与键盘导航，通过 props 接收目录数据，通过事件交还选择、打开与右键操作；`FilesView` 继续负责远端读写和文件操作。10,000 行模拟目录在 1040 × 720 视口初始只渲染 27 行，末尾 25 行。End / Enter、筛选后滚动复位通过浏览器检查。
- 不可见文档和 KeepAlive 后台页面停止指标轮询，同一会话不叠加未完成请求；旧请求的错误不会覆盖新服务器。终端隐藏或尺寸未变时跳过多余 PTY resize。
- 文本行数和 UTF-8 字节数合并为一次无大数组分配的扫描；输入统计延迟 180 ms，最长等待 500 ms。保存前仍立即校验当前完整草稿的 1 MB 限制。
- 修正 Esc 在同一次窗口事件中打开又关闭未保存确认框的问题；取消关闭保留草稿。

## 验证

- `pnpm build`：Vue / TypeScript 检查与生产构建通过。
- `pnpm test`：40 项通过，包括 UTF-8 / 超长草稿、图形边界、后台轮询、旧响应隔离、子窗口绘制等待与超时回退。
- `cargo test --locked --offline --lib`：105 项通过，包括编辑目标绑定、草稿状态、备份、SSH 与本地 PTY。
- `git diff --check`：通过。
- 浏览器检查：620 × 480 设置窗口、AI 设置延迟加载、远端文本编辑与模拟预览保存、未保存确认与取消、10,000 行目录导航与筛选、关闭重开设置后丢弃未保存草稿。
- 原生 Windows Acrylic 的桌面透视效果和点击到显示的实际耗时仍需运行桌面构建确认；浏览器不能呈现 DWM 效果。没有对真实 SSH 服务器执行写入。

## 复现界面检查

运行 `pnpm dev`，打开以下开发验证页面。这些页面只使用模拟文件，不会作为生产入口打包：

- `/tests/performance-preview.html`：远程文本编辑器，读写均由 Tauri mock 截获。
- `/tests/performance-preview.html?view=files`：10,000 个模拟文件，顶部显示实际渲染行数。
- `/tests/window-preview.html`：模拟原生关闭与重新打开通知，验证设置草稿的卸载与重建。

实现参考：[Vue 性能指南](https://vuejs.org/guide/best-practices/performance)、[Tauri WebviewWindow](https://docs.rs/tauri/latest/tauri/webview/struct.WebviewWindow.html)。
