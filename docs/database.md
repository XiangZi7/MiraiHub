# 数据库工作台

本文按 **v4.0.0（2026-11-09）** 源码核对，涵盖当前入口与各引擎差异。Redis 的使用方式见 [Redis 工作台](redis.md)。

## 连接与支持范围

在侧栏「数据库 → 新建连接」选择引擎。连接可以分组、添加标签，并参与最近连接与连接备份。

| 引擎 | 连接方式 | 能力与差异 |
| --- | --- | --- |
| MySQL | 地址、端口、账号与密码 | 数据 / 结构编辑、SQL、备份恢复、会话监控和用户权限管理 |
| MariaDB / TiDB | 表单中选择对应产品，后端使用 MySQL 协议 | 按服务端版本处理差异；索引、生成列、约束、分区等能力仍由服务端决定 |
| PostgreSQL | 地址、端口、账号、数据库与 SSL 策略 | 支持 schema 切换、数据 / 结构编辑、SQL、备份恢复、会话监控和角色权限管理 |
| SQLite | 选择或输入本地 `.db` / `.sqlite` / `.sqlite3` / `.db3` 文件路径 | 非只读连接可创建不存在的文件；不使用网络认证、SSL 或 SSH 隧道，无服务端用户与会话管理 |

网络连接可配置 SSL 策略、CA 和客户端证书。SSH 隧道可引用已保存的 SSH 连接或手动填写 SSH 信息，断开数据库会话时释放隧道；目标数据库地址从 SSH 服务器一侧访问。SQLite 不适用这些网络选项。

连接可标记为开发、测试或生产环境，并启用只读模式。只读模式在执行入口拒绝写操作，并结合数据库会话的只读设置。生产环境的 `DROP`、`TRUNCATE`、`ALTER`、无 `WHERE` 的 `UPDATE` / `DELETE` 等危险操作要求输入当前库名确认；尚未选库时使用界面提示的 `CONFIRM`。

连接失败面板可请求 AI 诊断，发送脱敏后的错误与连接摘要；不会自动重试修改凭据。

## 数据浏览与编辑

- 对象树浏览表、视图及引擎支持的过程 / 函数，支持过滤、刷新、右键操作和 PostgreSQL schema 切换。
- 表数据支持分页、排序、条件筛选、调整并记忆列宽、单元格编辑、新增、复制行、删除与改动预览；没有主键的行按界面限制只读。
- 待提交的数据改动在单个事务中提交，任一语句失败整体回滚；切页、切换筛选或关闭前会检查未提交改动。
- 外键单元格可跳转到引用的记录，也可查看引用当前行的记录；目标表打开时自动带上对应筛选。
- 大值查看器提供文本、可折叠 JSON、十六进制及可识别图片的预览。二进制内容只读，避免把编码文本误写为原始内容。
- 列标签规则可将枚举值显示为有颜色的标签，规则与列宽随所属表保存。

## SQL 编辑与结果

SQL 编辑器提供语法高亮、对象 / 字段补全、格式化、保存查询和连接级查询历史。运行时优先执行选区，也可只执行光标所在语句；执行中的查询可取消。

参数面板识别 `:name`、`?` 和 `$1` 占位符，填写后通过参数绑定执行。SQL 片段可在管理面板维护，正文支持 `${1:默认值}`、`$1`、`$0`，展开后用 Tab 切换占位位置。

每个查询标签保留近期执行结果，默认保留 5 次未固定结果，可固定需要对照的结果。结果行数据总内存有约 64 MiB 的估算预算，超出时可能只保留摘要；这些结果快照不是数据库备份。

| 操作 | 默认快捷键 / 入口 |
| --- | --- |
| 新建查询 | `Ctrl+N` |
| 执行选区或全部 SQL | `Ctrl+Enter` |
| 执行光标所在语句 | `Ctrl+Shift+Enter` |
| 格式化 SQL | `Shift+Alt+F` |
| 显示 / 隐藏结果区 | `Ctrl+J` |
| 刷新对象树 | `F5` |
| 聚焦对象树筛选 | `Ctrl+Shift+L` |
| AI 生成 / 改写 | SQL 编辑器内 `Ctrl+K` |
| 执行计划 | SQL 编辑器内 `Ctrl+E` 或右键菜单 |

执行计划用于查看优化器计划，不自动执行 `ANALYZE`；界面可展示计划树并结合相关索引辅助分析。

## SQL 与数据 AI 助手

先在「设置 → AI Agent」配置可用模型。以下为工作台内的辅助入口，与 Agent 对话共用模型配置，但一次性辅助请求不加入 Agent 聊天历史。

| 功能 | 使用方式与数据范围 |
| --- | --- |
| 生成 / 改写 SQL | 输入自然语言要求，利用相关表结构生成 SQL，查看差异后应用到编辑器 |
| 解释 / 优化 SQL | 在编辑器右键发起，返回说明与可用的 SQL 建议，应用前仍可核对 |
| 报错修复 | 从查询失败结果发起，发送失败语句与报错；接受修复后可重跑，失败时最多自动追加 2 轮建议，每次重跑仍需用户确认 |
| 内联补全 | 在「设置 → 快捷键 → 数据库」启用，默认关闭；开启后会发送光标前后 SQL 与已知列信息 |
| 结果问答与图表 | 发送列信息、前 50 行抽样及逐列统计，回答可附柱状图或折线图；抽样不代表完整数据集 |
| 测试数据 | 表右键打开生成器，AI 根据结构建议列规则，行数据及外键候选在本地生成 / 处理；预览后可写入 |
| 数据字典 | 选择表并导出 Markdown / HTML，可选 AI 补全缺失说明；业务数据抽样默认关闭 |
| 设计器辅助 | 根据自然语言生成或调整表设计草稿，再经过 DDL 预览与保存确认 |

测试数据生成支持序列、数值、布尔、枚举、日期、常见模拟字段与引用规则；写入走传输中心，在事务中分批执行，失败或取消会回滚。AI 不接收生成后的整批行数据。

数据字典默认只使用表结构。明确允许抽样后，每表最多取 5 行，每个值截取到 48 字符，并排除密码、Token 等已识别敏感字段；其他业务字段仍可能包含敏感信息。生成说明供审阅，不会自动回写数据库注释。

Agent 对话还提供相关表结构检索、索引读取及执行计划工具；权限模式与数据处理见 [AI Agent](ai-agent.md)。

## 结构设计、ER 图与结构对比

表设计器覆盖字段、主键、索引、外键及引擎支持的表选项，并提供 CHECK、触发器和分区相关编辑入口。生成列、表达式默认值、索引方法、前缀 / 降序索引等按引擎与版本处理，不能将所有选项视为跨库通用。

保存前预览 DDL。PostgreSQL / SQLite 的设计器批量 DDL 在事务中执行，失败整体回滚；MySQL DDL 逐条生效，中途失败前已执行的语句不会回滚。SQLite 部分修改需通过重建表完成，界面会给出相应说明。

工具栏「ER 图」按外键关系展示表之间的连接，可查看布局与关联。结构对比选择当前连接下的源库和目标库，比较表、字段及索引，生成使目标结构接近源结构的迁移 SQL；用户勾选后复制 SQL，再自行审阅执行。删除项与索引替换默认不选，主键、外键、特殊属性及部分 SQLite 变更会标记为需手动迁移。

结构对比不是跨引擎数据迁移工具，也不会直接同步业务数据。

## 导入导出与备份恢复

表和查询结果可导出为 SQL、Excel、CSV、JSON、TXT 或 HTML 数据字典。表数据可选择当前页或当前筛选范围；导入导出任务进入传输中心，支持进度查看及对应任务的取消。

Excel 导入仅向已有表追加数据，不创建或清空表；全部工作表在同一事务内写入，失败或取消回滚。SQL 导入按文件中的语句执行，应核对目标及文件内容。

「备份数据库」提供以下方式：

| 引擎 / 方式 | 行为 |
| --- | --- |
| MySQL 原生工具 | 备份使用 `mysqldump`，恢复使用 `mysql` |
| PostgreSQL 原生工具 | 备份使用 `pg_dump`，恢复使用 `psql` |
| 找不到原生工具 | 回退内置 SQL 导出 / 导入；内置备份不支持按表选择，需改为整库或配置工具 |
| SQLite | 生成数据库文件备份，优先 `VACUUM INTO`；文件备份需断开后替换原文件或作为新连接打开，不能当 SQL 文件恢复 |

MySQL / PostgreSQL 原生备份可选择结构、数据或全部内容，也可选择表；工具目录可以手动指定。备份面板记录本地备份历史、文件信息和运行日志。原生工具任务可请求取消，内置回退方式的取消能力不同，以界面结果为准。

这里备份的是数据库内容；「设置 → 备份与恢复」导出的是连接配置，二者用途不同。

## 会话与用户权限

MySQL / PostgreSQL 的工具栏提供「会话监控」及「用户与权限」：查看当前会话、运行 SQL、持续时间与相关状态，按权限取消查询或结束会话；管理 MySQL 账号 / PostgreSQL 角色及对应授权。操作需要当前数据库账号具备服务端权限，结束会话可能导致其未提交事务回滚。

SQLite 不提供这些服务端管理入口，不支持通过对象菜单修改或删除数据库；关闭连接不会删除本地数据库文件。
