# AI Agent

在设置 → AI Agent 中填写基础 API 地址、模型 ID 与 API Key，启用后保存并测试连接。服务需要支持 Chat Completions 的 function tools；不是 Responses 或原生 Anthropic 协议。默认不启用，不预填收费模型。仅在用户发送消息后调用服务。

SSH 工作区和数据库工作区都有 AI Agent 标签；分屏按钮在编辑器旁显示 AI。原有第二个 SSH 终端仍可从“新建或关闭第二个 SSH 终端”按钮打开。对话支持多轮追问、停止、清空、复制记录。

## 执行边界

- 自动只读：固定 Linux 系统/磁盘/进程名称/网络统计探针；数据库对象与字段结构（MySQL、PostgreSQL）。探针不接收任意 Shell 参数，元数据查询复用参数绑定。
- 所有自定义 Shell 和 SQL 都需审批，包括 SELECT/EXPLAIN：函数、CTE、脚本拼接可能产生副作用，不能仅靠字符串前缀判断只读。
- 后端校验工具名称、连接类型、严格参数结构、长度与控制字符；未知工具、额外字段、重复字段、并行调用均不执行。
- 审批包含后端记录的真实目标、完整原文、AI 提议原因，锁定在具体会话与数据库版本。审批 5 分钟到期，随机 ID，在锁内消费后才执行；不能重复使用或从模型工具中批准。
- 数据库使用独立连接池执行 AI 操作，避免手动编辑器中的 USE/SET 改变已批准 SQL 的初始目标。切库再切回也会使旧审批失效。批准的 SQL 本身若包含跨库引用或 USE，将按显示的完整 SQL 执行。
- 切换标签/连接、关闭 AI 面板、停止、清空或保存 AI 设置会撤销后续执行。停止不是回滚；已经开始执行的操作可能已提交或仍在远端运行。
- 每轮最多 8 次模型请求，工具输出传入模型最多约 16 KB，模型响应最多 1 MB，保留最多 32 个后端对话。Shell 通道读取最长 30 秒；SQL 单语句 20 秒、整个脚本 45 秒，最多保留每条语句前 20 行。驱动仍可能接收大型单行数据，读取业务数据时应自行限制范围。

## 凭据与数据

API 配置整体使用 Windows DPAPI 按当前操作系统用户加密，保存在应用数据目录的 ai-settings.bin；密钥不会回传给页面，不进入普通设置、连接导出或日志。其他平台未接入系统密钥存储时拒绝保存，不回退明文。运行时密钥仍需留在本机进程内存，DPAPI 不能防御同一用户权限下的恶意程序。

远程 API 强制 HTTPS，HTTP 只允许 localhost/127.0.0.1/::1。地址不得包含账号、密码、查询参数或片段；HTTP 重定向被禁用，服务错误仅显示状态码。更换服务地址必须重新输入密钥或明确清除旧密钥，避免误把旧密钥发往新服务。

聊天与操作记录只保留在应用内存。模型仅收到用户消息和所调用工具的结果，不自动读取 SSH 密码、私钥、环境变量或终端缓冲区。用户输入和已批准操作的输出可能包含敏感数据，界面持续说明其会被发送给配置的模型服务。清空本机对话不等于删除服务商已经接收到的数据。

模型文本与输出按纯文本显示，不解析 HTML，不从代码块执行命令。工具结果、数据库名称、日志都是不可信数据。提示词用于引导模型；真正的执行权限由 Rust 工具分派与审批状态机控制。

这些限制针对 AI 发起的操作，不改变用户手动操作终端/数据库的权限，也不是针对已被攻陷的桌面进程或远端服务器的隔离沙箱。

## 验证

- cargo test --offline --manifest-path src-tauri/Cargo.toml --lib
- node --test tests/*.test.mjs
- npm run build
- 界面使用临时模拟接口验证只读完成、审批前不执行、拒绝、单次批准、切换连接取消以及分屏。临时夹具不进入发布包。
- HTTP 测试使用本机临时服务，验证真实请求结构、工具响应解析、拒绝跳转、限制响应大小、错误不回显服务端秘密；DPAPI 测试进行真实加解密往返。
- 未配置真实模型密钥，未在生产 SSH/数据库上执行 AI 操作。

接口参考：[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Function calling](https://developers.openai.com/api/docs/guides/function-calling)。
